# YouTube AI Lab

**Testing the Limits of AI** - An AI-powered YouTube channel that creates content based on viewer comments.

## Quick Start
```bash
cd ~/youtube-ai-lab
source venv/bin/activate
python backend/app.py
```

## Access
- Dashboard: http://192.168.50.50:8056
- Project Directory: `~/youtube-ai-lab`
- Quick navigation: Type `yt` from anywhere

## Status
🚧 Under active development

## Hardware
- Intel NUC @ 192.168.50.50
- Ubuntu 24.04 LTS
- 32GB RAM, 3.6TB storage

## Stack
- AI: Ollama (Llama 3.1 8B + Llama 3.2 3B)
- TTS: Piper
- Backend: Python/Flask
- Video: FFmpeg
- Database: SQLite
